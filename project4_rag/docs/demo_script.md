# Demo 视频录制脚本（2 分钟）

## 录制前准备

1. 终端执行 `python src/app.py`，浏览器打开 http://127.0.0.1:5000（无需 API Key，离线即可）；
2. 浏览器缩放调至 90%，窗口宽度 1280 以上，提前打开《评估报告.pdf》备用；
3. 录屏软件（Win+G / OBS / QQ 录屏），麦克风测试，全程不要露真实 Key。

## 备选展示问题（时间充裕时加演）

- `面单打印位置偏移怎么校准`（英文/数字混写也能检索：offset、模板）
- `订单量超了套餐额度怎么办`（跨模块歧义题，可诚实讲已知局限）
- CLI 版：另开终端 `python src/cli_demo.py`，展示工程师/内部使用入口

# 模板⑧ 新用户 30 天激活任务表（按岗位下发，每周打卡）

> 下发方式：D18 培训后通过服务群/邮件发至每个席位，每周一公布完成榜。
> 设计逻辑：每周 2 个任务，从"看得到"到"跑得出价值"；任务全部在 15 分钟内可完成。

## 运营岗

### 第 1 周：熟悉订单工作台
- [ ] 任务 1：登录并处理 5 笔订单（审核、备注、标记发货），截图发群；
- [ ] 任务 2：用异常订单筛选项找出 1 笔待处理异常单并说明原因。

### 第 2 周：商品与库存联动
- [ ] 任务 3：完成 5 个平台商品与 SKU 映射；
- [ ] 任务 4：为 1 个核心 SKU 设置安全库存阈值，触发一次补货预警查看。

### 第 3 周：发货链路
- [ ] 任务 5：独立完成 1 笔订单的打单发货全流程；
- [ ] 任务 6：查看物流追踪页，说出 2 种异常物流状态的处理入口。

### 第 4 周：数据与提效
- [ ] 任务 7：订阅/查看一次经营日报并转发给负责人；
- [ ] 任务 8：在帮助中心自学 1 个进阶功能（推荐：批量改价/自动分派规则）。

## 仓储岗

### 第 1 周
- [ ] 任务 1：在 PDA/PC 端完成账号登录与仓库绑定；
- [ ] 任务 2：完成一次拣货任务并核对库位。

### 第 2 周
- [ ] 任务 3：完成一次入库登记（含在途采购单收货）；
- [ ] 任务 4：处理 1 笔缺货/少货异常单。

### 第 3 周
- [ ] 任务 5：完成一次库位盘点并提交差异；
- [ ] 任务 6：用库存查询说出 3 个 SKU 的可用/在途/锁定数量。

### 第 4 周
- [ ] 任务 7：走通一次发货打包称重流程；
- [ ] 任务 8：学习面单补打与物流商切换操作。

## 客服岗

### 第 1 周
- [ ] 任务 1：在客服工作台聚合查看 2 个平台的站内信；
- [ ] 任务 2：回复 3 条真实消息并使用一次快捷短语。

### 第 2 周
- [ ] 任务 3：创建并处理 1 张售后单（退款/退货）；
- [ ] 任务 4：关联订单查看物流状态并答复买家。

### 第 3 周
- [ ] 任务 5：设置 1 条自动回复规则；
- [ ] 任务 6：查看会话时长统计，找到自己的高频问题。

### 第 4 周
- [ ] 任务 7：把一个高频问题沉淀为团队共享短语；
- [ ] 任务 8：完成帮助中心客服模块自学测验。

## 老板/管理员岗

### 第 1 周
- [ ] 任务 1：查看角色权限设置，确认各岗位权限无误；
- [ ] 任务 2：在手机端/首页看一次当日经营概览。

### 第 2 周
- [ ] 任务 3：查看订单与发货监控大盘；
- [ ] 任务 4：设置 1 条库存/发货异常预警通知。

### 第 3 周
- [ ] 任务 5：导出一次经营报表并在内部周会使用；
- [ ] 任务 6：查看团队任务完成榜并在群内点评一次。

### 第 4 周
- [ ] 任务 7：参加 D30 验收会并提出下阶段需求；
- [ ] 任务 8：与 CSM 确认 1 个深度功能（库存/对账）启用时间。

## CSM 打卡管理规则

1. 每周一 10:00 公布上周完成率（按人/按岗位），连续 2 周 0 完成的席位触发私聊辅导；
2. 客户整体完成率 <60% 时，项目标记为激活风险，按项目① R3 对应 SOP 处置；
3. 全部完成的成员在 D30 验收会上颁发"启用之星"（电子证书/小权益），请老板颁奖。
